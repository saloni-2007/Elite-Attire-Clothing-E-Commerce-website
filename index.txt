API Structure:

Authentication APIs:

/register – that will used to register User
/login –  that will used to login User
/logout –  that will used to logout User
/forgot-password – Send password reset link or OTP to the user's email.
/reset-password –  that will be used to Reset Password using OTP
/change-password – Change password after login
/profile – Get logged-in user's profile details.
/update-profile – Update user's Profile information


Product APIs:

/products – Get all  available products
/product/:id – Get Single Product
/add-product – Add  a new product
/update-product/:id – Update product details
/delete-product/:id – Delete Product


Category APIs:

/categories – Get All Categories
/add-category – Add Category
/update-category/:id – Update Category
/delete-category/:id – Delete Category

Cart APIs:

/cart – Get User Cart
/add-to-cart – Add Product to Cart
/update-cart – Update Cart
/remove-from-cart/:id – Remove Product from Cart
/clear-cart – Clear Cart

Order APIs:

/place-order – Place Order
/orders – Get All Orders
/order/:id – Get Single Order
/cancel-order/:id – Cancel Order
/update-order-status/:id – Update Order Status

Payment APIs:

/payment – Make Payment
/payment-status/:id – Get Payment Status

Review APIs:

/add-review – Add Review
/reviews/:productId – Get Product Reviews
/update-review/:id – Update Review
/delete-review/:id – Delete Review

Wishlist APIs:

/wishlist – Get Wishlist:

/add-to-wishlist – Add Product to Wishlist
/remove-from-wishlist/:id – Remove Product from Wishlist

Address APIs:

/addresses – Get All Addresses
/add-address – Add Address
/update-address/:id – Update Address
/delete-address/:id – Delete Address
